# Changelog

## v0.1 - Modern UI preview

This is the first versioned desktop refresh of the PCSWMM Data Extractor.

### Added
- Modern dark desktop interface with clearer file-selection cards.
- Grouped extraction settings for ranked maxima, minimum, and custom nth values.
- Cleaner export-format selection and primary actions.
- Improved selected-file review window.
- Status line and progress feedback.
- PowerShell launcher that creates a local virtual environment and installs dependencies.
- Dependency list for repeatable setup.

### Compatibility
- The original `data_Extraction.py` is intentionally retained.
- Extraction and visualization logic continues to come from the original implementation.
- v0.1 focuses on presentation, launch/setup, and usability rather than changing calculations.
